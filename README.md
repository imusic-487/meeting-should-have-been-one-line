The single sentence that could have replaced an entire pointless meeting.

## Entry

> This meeting is just an email that took an hour to say 'yes'.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (61 characters, one line, one sentence)
and verifies it on read-back: UTF-8, 1–200 characters, a single line.
